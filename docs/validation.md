## 可以复查的命令

从仓库根目录运行；Python3标准库，浏览器检查另需已有Node >=22与Chrome/Chromium，不自动安装依赖。

```bash
python3 -m unittest discover -s tests -p '*_test.py' -v
python3 skills/html-mockup/assets/check-overflow.py skills/html-mockup/assets/template.html skills/html-mockup/assets/blocks.html --widths=390,768,1440
python3 skills/html-mockup/assets/check-overflow.py docs/delivery-report.html --widths=390,768,1440
```

检查默认保留Chrome沙箱。受控隔离容器确实不能启动时才显式传--no-sandbox，并披露；这不是关闭系统浏览器或操作系统安全设置。检查失败非零，不能说通过。

源码变动后重新运行受影响检查。HTML自包含、锚点和文件集合检查不替代实际视觉审阅；单测模拟不替代真实浏览器/真实Mermaid。

## 行为测试的解释

制作前基线已能识别部分范围/外设/权限风险，但缺长期原型与评审索引、统一资料状态和运维/交接路径；本包围绕这些实际缺口补强，不声称基线全部错误。
独立代理在隔离临时目录以合成场景应用随包技能，root复核实际文件和检查结果。结果只覆盖测试场景，不能保证所有行业或未来模型都不漏项。
本轮没有真实收款、真实个人数据、收费模型调用、硬件/真机集成、行业法规验收或业务生产发布。

## 其他限制

- 当前版本仍是draft；GitHub保存/笔记摘要不是安装。现有全局html-mockup未修改，业务仓库未改。
- 候选热度/许可调查快照为2026-10-28；未来采用时复查官方信息、具体版本兼容和所有依赖许可。
